MY LOVE MODERN BIRTHDAY WEBSITE

FOLDER STRUCTURE
----------------
index.html
assets/
  css/style.css
  js/app.js
  images/memory-01.jpg ... memory-14.jpg

HOW TO PREVIEW
--------------
1. Open index.html with Chrome.
2. Keep all files and folders in the same structure.

HOW TO UPLOAD TO GITHUB PAGES
-----------------------------
1. Create a new public repository on GitHub.
2. Upload the whole project:
   - index.html
   - assets folder
3. Commit the files.
4. Open Settings > Pages.
5. Under Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
6. Save.
7. Your link will look like:
   https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

IMPORTANT
---------
Do not rename or move files inside the assets folder unless you also update the paths in index.html and assets/js/app.js.
